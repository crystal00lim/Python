# Python
Python codes created in 2022-2024
The gseaFilter code filters genes that pass a certain FDR-q-value and grabs its enrichment graph along with other information pertaining to the gene.
A table of all the genes is then produced at the end of the gseaFilter code that gets fed into the UpsetPlot code. 
The upsetplot code basically compares all the genes across different gsea results and visualizes which genes are most abundant according to each sample.
